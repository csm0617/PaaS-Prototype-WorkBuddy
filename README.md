# PaaS-Prototype-WorkBuddy

云原生 PaaS 平台的高保真交互原型。纯静态实现（HTML + CSS + JS），无构建、无外部依赖，浏览器直接打开即可体验。

## 业务模型

三层结构：**应用 → 组件 → 工作负载**，分别对应业务交付边界、构建发布边界、调度运行边界。

## 模块化设计

Service Mesh 与云边端协同为可插拔模块，可独立开关。关闭时相关 UI 整体收缩（页签锁定、表格整列移除），而非留空占位，基础功能不受影响。

## 打开方式

双击 `index.html`，或：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

## 目录结构

```
index.html        入口，挂载应用与路由
assets/style.css  设计系统与组件样式
assets/data.js    演示数据（应用/组件/工作负载、Mesh、边缘、流水线）
assets/app.js     路由、状态、视图渲染
```

## 建议体验路径

1. 平台管理 → 模块管理：关闭 Service Mesh，观察应用详情页签与表格列的变化
2. 应用列表 → 智慧零售中台：左侧资源树逐层下钻三层模型
3. 应用详情 → 组件拓扑：查看自动布局的组件依赖图
4. 流水线 → order-service · 主干发布：8 阶段流程与实时日志
